⏰ Default Schedule
─────────────────────────────────────────────
Every Monday at 2:00 AM (server time)

All enabled sites will be scanned automatically!


⚙️  Change Schedule
─────────────────────────────────────────────
Edit .env file:

  SCAN_SCHEDULE=0 2 * * 1  # Cron format

Examples:
  0 0 * * *    = Daily at midnight
  0 */6 * * *  = Every 6 hours
  0 0 * * 0    = Every Sunday

📝 Edit .env File
─────────────────────────────────────────────
PORT=3000                    # Web server port
WCAG_LEVEL=AA                # A, AA, or AAA
INCLUDE_WCAG_22=true         # Include WCAG 2.2 rules
SCAN_TIMEOUT=30000           # 30 seconds per page
MAX_CONCURRENT_SCANS=3       # Scan 3 sites at once
